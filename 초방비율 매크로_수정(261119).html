초방비율 매크로

통합 업로드 파일을 초방비율용 목록으로 변환하고, 통합편성표에서 편성 길이를 찾아 초방비율 파일의 방송시간·초방일·비고까지 한 화면에서 입력합니다. 파일은 이 컴퓨터 안에서만 처리되며 어디에도 전송되지 않습니다.

빌드 2026-11-18 · 변환 시트 행 높이 17.4

1. 파일 올리기

엑셀 파일 3개를 한 번에 끌어다 놓거나 클릭해서 선택하세요 통합편성표 · 통합 업로드 파일 · 초방비율 파일 (순서 상관없이 자동으로 구분합니다)
통합편성표주간 편성표 시트가 들어 있는 파일
통합 업로드 파일str1~str8 열이 있는 업로드 파일 (XLSX, XLS, CSV)
초방비율 파일 (입력 대상)"초방 프로그램 리스트" 상세 내역 파일
First-window 규칙과 다운로드 파일명에 쓰입니다. 통합편성표의 시트 이름에서 채널을 찾으면 자동으로 선택합니다.

변환 결과 미리보기 (최대 100행)

4. 확인

칸 길이, 시작~칸 끝, 편성 간격 세 가지 계산값을 모두 보여주며, 굵게 표시된 값이 현재 기준으로 입력됩니다. 회색 행(비초방)은 입력하지 않습니다. "찾지 못함"과 "확인" 행은 편성명·초방일·비고는 그대로 입력하고, 방송시간 칸만 노란색으로 표시합니다(찾지 못함은 값이 비어 있습니다).

5. 저장

원본 파일은 바꾸지 않습니다. 초방비율 파일에 이전 내용이 적혀 있어도 모두 지우고 새로 올린 파일 기준으로 다시 입력합니다. 프로그램명, 방송시간(편당·총), 초방일(YYYY-MM-DD), 비고(First-window) 칸만 채우며 듀레이션을 확인하지 못한 편성은 방송시간 칸을 노란색으로 표시하고, 제목·헤더·서식·수식은 원본 그대로 둔 새 파일을 내려받습니다. 초방일은 초방비율용 목록의 년·월·일(B·C·D열) 날짜 그대로입니다.
